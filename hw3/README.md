| A | B | C | A ∧ B | ¬C | F = (A ∧ B) ∨ ¬C |

| 0 | 0 | 0 | 0 | 1 | 1 |
| 0 | 0 | 1 | 0 | 0 | 0 |

### 2. Спрощення логічного виразу

Вираз із завдання:

```text
¬(A ∨ B) ∧ (A ∨ B)
```

За законом де Моргана:

```text
¬(A ∨ B) ∧ (A ∨ B)
= (¬A ∧ ¬B) ∧ (A ∨ B)
```

Розкриваємо дужки за дистрибутивним законом:

```text
= (¬A ∧ ¬B ∧ A) ∨ (¬A ∧ ¬B ∧ B)
```

У кожному доданку є протилежні значення однієї змінної. За законом протиріччя `¬A ∧ A = 0` і `¬B ∧ B = 0`, тому:

```text
= (0 ∧ ¬B) ∨ (¬A ∧ 0)
= 0 ∨ 0
= 0
```

Отже, вираз завжди дорівнює `0`: умови `A ∨ B` та `¬(A ∨ B)` не можуть бути істинними одночасно.
