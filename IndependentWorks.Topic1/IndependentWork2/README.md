## Завдання №2

```csharp
using System;
using System.Text;

string text = "Кур’ер";
byte[] bytes = Encoding.UTF8.GetBytes(text);

Console.WriteLine($"Рядок: {text}");

int byteIndex = 0;
foreach (char symbol in text)
{
    byte[] symbolBytes = Encoding.UTF8.GetBytes(new[] { symbol });
    string hexBytes = BitConverter.ToString(symbolBytes).Replace("-", " ");

    Console.WriteLine($"{symbol} - U+{(int)symbol:X4} - {hexBytes}");
    byteIndex += symbolBytes.Length;
}

Console.WriteLine($"Усього: {byteIndex} байтів UTF-8");
```

## Завдання №3

Ми можемо порівняти довжину рядка в символах і в байтах. Рядок **«Кур’ер»** містить **6 символів**, але його UTF-8 представлення займає **13 байтів**. Ця різниця виникла через те, що деякі символи використовують більше одного байта.

У цьому рядку:

- **5 символів кодуються двома байтами** — п’ять українських літер;
- **1 символ кодується трьома байтами** — typographic apostrophe `’`;
- **0 символів кодуються одним байтом**;
- **0 символів кодуються чотирьма байтами**.

Тому довжина в символах дорівнює 6, а довжина в байтах — 13. Вона не може бути визначена лише кількістю символів, оскільки кожен символ може мати різну довжину кодування.
