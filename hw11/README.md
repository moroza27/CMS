# Домашня робота з лекції № 11

### 1. Розрядність АЦП

Діапазон датчика становить `U_max = 5 В`, а потрібну зміну напруги задано як `ΔU = 50 мВ = 0,05 В`. За умовою:

```text
2^N > U_max / ΔU
2^N > 5 / 0,05
2^N > 100
```

Оскільки `2^6 = 64`, а `2^7 = 128`, мінімальна розрядність — **N = 7 біт**. Крок квантування для 7-бітного АЦП на діапазоні 0–5 В:

```text
q = U_max / 2^N = 5 / 128 ≈ 0,03906 В ≈ 39,1 мВ
```

Крок менший за 50 мВ, отже АЦП може розрізняти задані зміни напруги.

### 2. GPIO і pull-up резистор

Якщо вхід мікроконтролера не підключений ні до логічного нуля, ні до логічної одиниці, він є floating-входом і не має визначеного рівня напруги. На нього можуть впливати електричні завади, тому покази можуть випадково змінюватися між 0 і 1. Pull-up резистор підтягує вхід до живлення й задає стабільний логічний рівень, коли кнопка не натиснута. Під час натискання кнопка з'єднує вхід із землею, і на вході читається стабільний логічний 0.

### 3. Приклад використання PWM

PWM доцільно використати для керування яскравістю світлодіода. Звичайний цифровий вихід GPIO може лише вмикати або вимикати світлодіод, а PWM швидко перемикає його з різною часткою часу у ввімкненому стані. Зміною коефіцієнта заповнення можна регулювати середню потужність і, відповідно, видиму яскравість.
