# Домашня робота з лекції № 14

## 1. Розшифрування MAC-адреси

Для прикладу візьму MAC-адресу з умови: `08:00:27:E7:A2:C3`. Її можна поділити на дві частини:

| Частина адреси | Значення | Призначення |
|---|---|---|
| Перші 3 байти (OUI) | `08:00:27` | Ідентифікатор, виділений виробнику мережевого обладнання |
| Останні 3 байти | `E7:A2:C3` | Частина, яку виробник використовує для розрізнення пристроїв у межах цього OUI |

Останні три байти іноді описують як унікальну частину адреси пристрою, але це не обов'язково серійний номер у звичайному розумінні. Наведене розділення відповідає типовій MAC-адресі з глобально призначеним OUI.

## 2. Як комутатор заповнює таблицю MAC-адрес

Початково таблиця MAC-адрес комутатора порожня. Коли пристрій A надсилає перший кадр до пристрою B, комутатор виконує такі дії:

1. Кадр надходить на порт 1. Комутатор читає MAC-адресу джерела `AA:AA:AA:11:11:11` і запам'ятовує відповідність: `AA:AA:AA:11:11:11 → порт 1`.
2. Комутатор шукає адресу призначення `BB:BB:BB:22:22:22` у своїй таблиці, але поки її там немає.
3. Оскільки адреса призначення невідома, комутатор розсилає кадр через усі порти, крім порту, з якого кадр надійшов. У цій схемі він передає кадр через порт 2 до пристрою B.
4. Коли пристрій B відповідає, його кадр надходить на порт 2. Комутатор запам'ятовує другу відповідність: `BB:BB:BB:22:22:22 → порт 2`.
5. Після цього комутатор уже знає обидві адреси й передає кадри між пристроями через потрібний порт, не розсилаючи їх на всі порти.

Після навчання таблиця має такий вигляд:

| MAC-адреса | Порт |
|---|---:|
| `AA:AA:AA:11:11:11` | 1 |
| `BB:BB:BB:22:22:22` | 2 |

## 3. MAC- та IP-адреса основного мережевого інтерфейсу

Для активного бездротового інтерфейсу Windows (Wi-Fi) під час перевірки командою PowerShell отримано:

| Інтерфейс | MAC-адреса | IPv4-адреса |
|---|---|---|
| Бездротова мережа | `14-F6-D8-49-D4-A5` | `192.168.1.5` |

IPv4-адреса належить локальній мережі. MAC-адреса наведена у форматі з дефісами; її можна записати і з двокрапками: `14:F6:D8:49:D4:A5`.
